# 《物候》概念文档 v0.1

> 引擎：Godot 4 ｜ 时间模型：**离散时刻切换** ｜ 评审强度：lean
> 一句话：**你手上的东西不随时间变化，世界上的东西会。**

---

## 1. 游戏名提案

| # | 中文名 | 英文名 | 命名逻辑 |
|---|---|---|---|
| **A ⭐** | **物候** | **Seasons of Things** | 「物候」本义即「万物随节令呈现的周期性现象」，精确对应「同一物体在不同时刻呈现不同形态」这一核心机制；自带中文质感与考古学气质 |
| B | 锈时 | Rustline | 以最强视觉母题「锈蚀」命名，直白好记；缺点是只覆盖「衰变」一侧，盖不住「生长/位移」 |
| C | 溯形 | Retroform | 强调「追溯物体曾经的形态」，动作感强，偏科幻冷调 |

**推荐 A《物候》**，副标题可作「一把钥匙的四段人生」；B 作海外发行备选（Rustline 更易传播）。

## 2. 三根设计支柱（Pillars）

| 支柱 | 一句话主张 | 它如何约束设计决策 |
|---|---|---|
| **P1 · 一物一史** | 每个道具都是一条独立的时间线；谜题的答案永远是「它在某个时刻长这样」，而不是「合成出新东西」 | 禁止背包合成系统；禁止道具数量膨胀；单关可交互实体 ≤ 9；新增内容优先给老道具加时刻，而不是加新道具 |
| **P2 · 时间可见** | 时间不是抽象数值，而是可观察、可对比、可预演的**空间信息** | 每次切时刻必须有全场可感知反馈；时刻区分**至少两种非色彩通道**（刻度符号 + 光照角度 + 环境音 + 粒子）；必须提供「残影叠加」预览；禁止「看不见当前是第几刻」 |
| **P3 · 永不惩罚** | 玩家永不因试错受罚；任何死局都可无损回溯 | 无死亡、无 Game Over 结算画面；撤销可回到任意历史节点且返还资源；提示分 3 级递进而非直接给答案；无倒计时、无实时压力 |

## 3. MDA 分析

### Mechanics（机制 — 我们造了什么）
1. **离散时刻切换**：世界在 N 个固定时刻间整体切换（不是连续 scrub，不是录制回放）
2. **道具状态链**：每个实体在每个时刻有预设的（形态 / 位置 / 可用性 / 标签）四元组
3. **手持冻结**：玩家背包内的道具免疫时刻变化，保留拾取瞬间的形态
4. **覆盖与正向传播**：玩家的操作写入时间线，只影响「更晚的时刻」，绝不回写过去
5. **时砂资源 + 背包容量 + 形态锁**：三重约束，防止无脑穷举
6. **撤销栈 / 残影观察**：支持任意回溯与跨时刻对比

### Dynamics（动态 — 玩家实际会怎么玩）
1. **先看后动**：玩家会先横扫全部时刻建立「真值表心智模型」，再动手 —— 观察是核心动词，不是附属功能
2. **寻找「对的那一刻」**：卡住时的第一反应是「我要的状态在哪个时刻」，而不是「我缺什么道具」
3. **携带策略**：玩家会把过去的完好形态「偷渡」到现在使用（把新钥匙带回锈时）
4. **谨慎搬运**：意识到取走过去之物会让它在未来消失，产生「我该不该动它」的犹豫 —— 这是本作的核心张力
5. **时间园艺**：后期玩家会主动「在过去种下改变，到未来收获结果」（过去拔藤 → 现在通路）

### Aesthetics（美学 — 我们想要什么体验）
1. **发现（Discovery）**：翻找一件物品的全部人生
2. **顿悟（Aha）**：「原来它那时候是好的」这一瞬间的智性快感
3. **时间考古（Fantasy）**：玩家扮演的不是英雄，是**时间的考古学家**
4. **秩序感（Submission / 条理）**：真值表本身的美感 —— 世界是干净、可读、可穷尽的
5. **物哀（Mono no aware）**：万物必经成住坏空，衰变既是谜题也是叙事

## 4. 玩家心理学

### 自我决定论（SDT）
| 需求 | 本作如何满足 |
|---|---|
| **自主 Autonomy** | 时刻可任意自由切换（无顺序限制）；谜题常有多解路径；无强制引导箭头；随时可撤销重来 |
| **胜任 Competence** | 难度阶梯清晰；顿悟时有明确的多通道正反馈（画面 + 音效 + 时刻刻度跳动）；「最少切换次数」评星给高手额外目标 |
| **关联 Relatedness** | 每件道具自带叙事条目（熔炉的刻痕、钥匙柄上的名字、工匠留下的字条）；玩家与「过去的陌生人」产生跨时间连接 |

### 心流平衡
- **难度由三维递增**：时刻数（3→4→5）× 实体数（3→6→9）× 约束数（形态锁 / 时砂 / 背包容量），**不靠操作精度或反应速度**
- **焦虑缓冲**：撤销 + 3 级提示 + 无倒计时，把「卡住」从惩罚变成思考时间
- **节奏**：每个谜题 2–6 分钟；关卡间用叙事条目做呼吸点

### Bartle 玩家类型
- **主干：Explorer（探索者）** —— 热爱发现隐藏信息与系统边界。服务方式：残影观察、跨时刻对比、可收集的叙事条目、隐藏的「第四时刻」彩蛋
- **辅助：Achiever（成就者）** —— 服务方式：最少步数 / 最少切换次数评星、全条目收集
- 明确**不服务** Killer（无对抗）、对 Socializer 仅提供轻量的「分享你的解法步数」

## 5. 核心动词（动词优先法，5 个）

| # | 动词 | 说明 | 输入（默认键位） |
|---|---|---|---|
| 1 | **切换 Shift** | 在已解锁的离散时刻间前后移动当前时刻 | `A` / `D` 或 `←` `→` |
| 2 | **持取 Take**（含放置） | 把世界中可取之物拿进背包 / 放到脚下或目标格；重物推移也复用此动词 | `空格` |
| 3 | **使用 Use** | 对目标使用手持物或直接操作目标（开锁、拔藤、扳闸、放下到压力板） | `E` / 鼠标左键 |
| 4 | **观察 Observe** | 查看条目详情；长按开启**残影叠加**（同物体全部时刻半透明同屏） | `Tab`（长按） |
| 5 | **回溯 Undo** | 撤销上一步 / 打开时间轴撤销到任意历史节点 / 重置时刻 | `Z` |

> 辅助键：`H` 请求提示。全部键位可重映射。
> **设计红线**：动词总数锁死为 5。任何新玩法必须先尝试用这 5 个动词表达；新增动词需主理人批准。
> **键位冲突已排查**：`E` 只绑定 Use，不复用为切时刻。

## 6. 范围分层

### MVP（本次只做这一层）
1. 4 个离散时刻的全局切换 + 完整视觉/听觉反馈
2. 道具状态链数据结构 + 覆盖/正向传播求解器（resolve）
3. 5 个核心动词 + 背包（容量 2，手持冻结）
4. 撤销栈（可回到任意历史节点）+ 3 级提示
5. 试玩关卡 1 关（教学关，含真值表、3 个谜题、可通关）

### 目标（上线版本）
1. 6–8 关正式关卡 + 3 种谜题语汇组合关
2. 时砂资源系统 + 时刻锁定/解锁（时间裂纹）
3. 叙事条目收集与「物志」图鉴
4. 最少步数评星 + 关卡选择
5. 完整可访问性选项（色盲模式、键位重映射、字幕/音效提示）

### 远景（不做承诺）
1. 局部时刻（同一场景不同物体处于不同时刻）
2. 时刻并行（分身/同步解谜）
3. 关卡编辑器与创意工坊
4. 时间分支存档（多条时间线并存）

## 7. 视觉锚点（给美术的种子）

1. **色温分期 + 冗余编码**：T0 冷蓝灰（晨）→ T1 暖黄（昼）→ T2 橙褐（昏）→ T3 灰白（夜）。**每个时刻另配罗马数字刻度 Ⅰ/Ⅱ/Ⅲ/Ⅳ、独特光照角度、独特环境粒子**（T0 火星、T1 浮尘、T2 锈屑、T3 落灰）—— 色彩只是第 4 条通道，色盲玩家靠前三条也能分辨
2. **轮廓守恒，材质渐变**：同一物体在不同时刻**共享同一剪影**，只变材质、细节与侵蚀层级。这是玩家能认出「这是同一个东西」的唯一保证，是硬约束
3. **时代质感**：废弃钟械工坊 / 机械工坊前厅，蒸汽时代前夜的手工感；木、黄铜、锻铁、锈迹；避免高科技发光材质
4. **UI 隐喻 = 黄铜刻度尺**：时间轴是一条横向黄铜刻度尺 + 游标指针，**不是进度条**；切换时刻时游标滑动并伴随机械咬合音；残影以老照片多重曝光的形式叠加
5. **衰变分级**：侵蚀用 0–3 级表现（0 崭新 / 1 使用痕迹 / 2 锈斑 / 3 崩解），跨时刻读图时一眼可读
