# ADR-003：输入映射与反馈表现（对齐 GDD 5 动词）

- **状态**：已采纳（对齐 GDD §2.3、§5、§7.3、concept_doc §5）
- **决策者**：engineering-lead
- **关联**：architecture.md §2.1 / §4；硬约束"可 headless 验证"

## 上下文
需定义：(1) 玩家如何切换时刻与交互；(2) 无图形界面 / headless 环境下如何反馈与验证。硬约束：逻辑层必须可在无图形环境被断言。GDD 已锁死 **5 个核心动词**（切换/持取/使用/观察/回溯），键位已排查冲突（`E` 只绑 Use，不复用为切时刻）。

## 决策

### 1. 输入映射（5 动词 + 辅助）
| 动词 | 键鼠 | 手柄 | 说明 |
|---|---|---|---|
| 切换 Shift | `A`/`D` 或 `←`/`→` | `LB`/`RB` | `step_forward/backward`；⚠️ `E` 不可复用 |
| 持取 Take（含放置/推移） | `空格` | `A` | 拿进背包/放到目标格/重物推移 |
| 使用 Use | `E` / 鼠标左键 | `X` | 开锁/拔藤/扳闸/压板 |
| 观察 Observe（长按残影叠加） | `Tab`（长按） | `Y` | 查看条目 + 残影叠加（同物全时刻半透明同屏） |
| 回溯 Undo | `Z`（长按打开时间轴） | `B` | 单步/时间轴/重置 |
| 提示 Hint | `H` | — | 3 级递进，不消耗时砂、不计步 |

- 输入在 `project.godot [input]` 声明，代码用 `Input.is_action_just_pressed`。
- **全部可重映射**（可访问性）。

### 2. 切换反馈（GDD §2.3，5 通道冗余，色盲安全）
| 通道 | 规格 |
|---|---|
| 视觉 | 全屏色调插值 + 光照角度旋转（0.35 s，Tween + 全局 shader） |
| HUD | 黄铜刻度尺游标滑动 + 罗马数字 Ⅰ–Ⅳ 跳动 + 当前刻度高亮 |
| 音效 | 机械咬合音 + 切换后环境音交叉淡入 |
| 粒子 | 环境粒子整体替换（火星→浮尘→锈屑→落灰） |
| 物体 | 形态/位置变化实体播 0.25 s 变形动画（不做瞬移） |
- **禁止**"只有色调变化"的切换（违反支柱 P2）。
- **边界**：到头不循环，游标撞底 + "卡住"音效（非静默失败）。
- **冷却**：0.35 s 过渡，输入被吞（防连点）。

### 3. 逻辑反馈（headless 可见，硬约束落地）
- 全部经**类型化信号 + 结构化数据**：`moment_changed(t)` / `hourglass_changed(left,cap)` / `backpack_changed` / `override_added(o)` / `deadlock_detected` / `goal_reached`。
- headless 测试直接断言信号与 `current_t`/`resolve_state` 结果，**不依赖任何渲染**。

### 4. 视觉反馈（有界面时，全程序化）
- `TimeRuler`（刻度尺）、`HourglassHUD`（沙漏，常驻）、`BackpackHUD`（2 格，常驻）、`HintLayer`（3 级提示）、`UndoControl`。
- 系统字体 `Label`（罗马数字/叙事）+ `ColorRect`/`Polygon2D`/`_draw()`。**零外部美术。**

### 5. 可访问性（GDD §10）
- 键盘全操作；5 通道冗余，色盲靠罗马数字+图案而非色相。
- **高对比时刻模式**：T0 斜线阴影 / T1 无阴影高亮 / T2 点状纹理 / T3 网格纹理（图案而非色相）。
- 残影叠加可关闭（晕动症）；过渡可改瞬时（前庭敏感）；无闪烁（癫痫安全）。
- 无文字依赖：全部反馈同时给图标+音效+形态动画。

## 备选与取舍
- **连续 scrub / 录制回放**：违背"离散时刻"拍板，增加渲染负担 → **否决**。
- **纯视觉反馈**：无法 headless 验证，违背硬约束 → **否决**。

## 后果
- **正向**：输入确定可模拟；反馈可断言；headless 覆盖"切换→resolve→派生→判定"全链路。
- **负向**：视觉克制（程序化几何+系统字体），风格化受限——lean 可接受。
- **可测性落地**：`tests/` 用 `--headless --script`，断言信号与状态，无需窗口（配合 `godot-headless-verify`）。
